# Finance Tracker

Full-stack finance tracking application built with:

- FastAPI (Python)
- React (Vite)
- MongoDB
- Recharts

## Features
- Transaction tracking
- Subscription detection
- Spending analytics
- Interactive dashboard
- CRUD operations

## Setup

### Backend
1. cd backend
1.  pip install -r requirements.txt
1.  uvicorn app.main:app --reload

### Frontend
- cd frontend
- npm install
- npm run dev
