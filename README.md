# Finance Tracker

Full-stack finance tracking application built with:

- FastAPI (Python)
- React (Vite)
- MongoDB
- Recharts

## Features
- Transaction tracking
- Subscription detection
- Spending analytics
- Interactive dashboard
- CRUD operations

## Setup

### Backend
- cd backend
- pip install -r requirements.txt
- uvicorn app.main:app --reload

### Frontend
- cd frontend
- npm install
- npm run dev
